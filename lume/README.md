# LUME — Site institucional / investigação

Site fictício da LUME para a campanha. A camada pública foi construída para parecer um site corporativo real, enquanto notícias, pessoas, lugares, imagens e registros permitem que os jogadores montem conexões por conta própria.

## Estrutura principal
- `index.html` — homepage
- `empresa.html` — história e áreas da LUME
- `gideon.html` — perfil público de Gideon Thorne
- `noticias.html` — central de notícias e arquivo
- `medicina.html`, `energia.html`, `pesquisa.html` — áreas institucionais
- `elise-vautrin.html` — perfil público da artista apoiada pela Fundação LUME
- `noticia-*.html` — comunicados e registros históricos
- `style.css` — identidade visual e responsividade
- `script.js` — interações e ordenação do arquivo
- `assets/` — imagens e identidade visual

## Observação de projeto
As informações públicas não explicam a campanha nem apontam quais itens são pistas. A intenção é que conexões como LUME → arte/percepção → Élise Vautrin, LUME → pesquisa cognitiva → Calisto Noir e LUME → instituições de Paris sejam descobertas pela comparação dos registros.

Abra `index.html` no navegador para visualizar.
